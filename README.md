# Actu spéciale Edith

Le canal des versions d'**Edith**, la mentore digitale conçue par [Devlogy](https://www.devlogy.com) (Abidjan).

Edith évolue sur son **instance zéro**, chez Devlogy. Chaque nouvelle version est annoncée ici. Les Edith installées chez les clients lisent ce canal pendant leur veille du lundi et du jeudi : leur admin voit la note de version en premier, puis l'applique en une phrase à Claude, avec le plugin Edith. L'équipe découvre ensuite les nouveautés dans « Nouveau chez Edith ».

Ce dépôt ne contient que les notes de version :

- [`versions.json`](versions.json) : le fichier lu par les Edith des clients ;
- [`CHANGELOG.md`](CHANGELOG.md) : le même journal, à lire.

Le code d'Edith n'est pas ici : il est livré par le plugin Edith, que Devlogy remet à chaque organisation cliente.

Dernière version : **2.0.0** (2026-10-29).
